# Resumen de Git

## Que es git?
Git es un sistema de control de versiones que permite guardar 
el historial de cambios de un proyecto.

## Flujo basico
Los pasos principales son status, add, commit y push.

### Que es Git y para que sirve?
Git es para controlar las versiones y sirve para guardar un 
historial de nuestro desarrollo.

### Que diferencia hay entre el repositorio local y repositorio remoto (GitHub)?
De manera local puedo modificar datos sin afectar a los demas 
contribuidores y el remoto es el proyecto definido para todos 
con cambios importantes en produccion.

### Cuales son los pasos del flujo basco de Git (status, add, commit, push) y que hace cada uno?
El flujo es de primero agregar los archivos a editar (agregando, 
eliminando o editando) para luego "empacarlos" con un distintivo
teniendo un nombre que los identifica.
* `status`: nos dicta con que esta conectado el repositorio local a uno remoto.
* `add`: sirve para agregar todos los cambios entre versiones.
* `commit`: es apartar todos los cambios a cada archivo y guardarlos con un identificador de version.
* `push`: se publica o sube al repositorio remoto los datos del local.
